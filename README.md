# RimWorld Holsters

Holsters is a RimWorld mod that visually represents equipped weapons on pawns written in C# for RimWorld’s Unity-based modding environment
The goal is to improve in-game clarity and immersion while staying lightweight and compatible with the wider mod ecosystem.

## What this mod does

* Renders equipped weapons on pawns in real time
* Hooks into RimWorld’s existing equipment and rendering systems
* Avoids altering gameplay balance or pawn behaviour
* Aims to coexist cleanly with other mods
